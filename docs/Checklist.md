# Чек-лист проверок приложения PianoBar

**Приложение:** PianoBar (магазин музыкальных инструментов, WPF .NET 8)  
**Тестировщик:** Гуща Анна  

| ID | Раздел | Проверка | Результат | Примечание |
|---|---|---|---|---|
| CT-01 | Установка и запуск | Запуск приложения из исполняемого файла | Passed | Открывается окно каталога без ошибок |
| CT-02 | Авторизация | Вход существующего пользователя с корректным логином и паролем | Passed | Сессия открывается, в шапке отображается профиль |
| CT-03 | Авторизация | Вход с неверным паролем | Passed | Выводится сообщение «Неверный логин или пароль» |
| CT-04 | Авторизация | Регистрация нового клиента с валидными данными | Passed | Учетная запись сохраняется в БД |
| CT-05 | Каталог | Отображение списка товаров с фото, ценой и остатком | Passed | Карточки загружаются корректно |
| CT-06 | Каталог | Фильтрация товаров по категориям и производителям | Passed | Список обновляется при выборе фильтра |
| CT-07 | Каталог | Поиск по названию инструмента | Passed | Находит товары по подстроке |
| CT-08 | Корзина | Добавление товара в корзину из общего каталога под гостем | Passed | Появляется требование авторизации |
| CT-09 | Корзина | Добавление товара из карточки товара под гостем | Failed | Баг 001: товар кладется в корзину без входа |
| CT-10 | Корзина | Увеличение количества товара кнопкой «+» выше складского остатка | Failed | Баг 002: счетчик растет без ограничения |
| CT-11 | Корзина | Уменьшение количества товара до 0 | Passed | Позиция удаляется из корзины |
| CT-12 | Корзина | Пересчет итоговой стоимости при изменении количества | Passed | Сумма пересчитывается автоматически |
| CT-13 | Заказы | Оформление заказа с валидным адресом, датой и временем доставки | Passed | Заказ создается, статус «Ожидает подтверждения» |
| CT-14 | Заказы | Попытка оформления заказа с датой доставки в прошлом | Passed | Ошибка валидации даты |
| CT-15 | Заказы | Списание количества товара со склада после оформления заказа | Passed | `StockQuantity` уменьшается в базе данных |
| CT-16 | Заказы | Отмена заказа клиентом в личном кабинете и возврат остатков | Failed | Баг 003: статус меняется на «Отменен», но товар на склад не возвращается |
| CT-17 | Админка | Вход под администратором и доступ к панели управления | Passed | Доступны разделы управления товарами и заказами |
| CT-18 | Админка | Добавление нового товара в каталог через админ-панель | Passed | Товар появляется в общем каталоге |
| CT-19 | Админка | Смена статуса заказа (например, на «В доставке», «Завершен») | Passed | Статус обновляется и виден клиенту |
