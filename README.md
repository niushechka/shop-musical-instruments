# Shop of Musical Instruments (PianoBar)

Десктопное приложение для автоматизации работы магазина музыкальных инструментов (каталог с фильтрацией, корзина, оформление заказов, роли клиента и администратора).

Проект разработан на C# / WPF в рамках курса «Объектно-ориентированное проектирование и программирование», а также использован в качестве объекта тестирования по дисциплине «Тестирование ПО».

## Технологический стек
* **Язык и платформа:** C#, .NET 8, WPF (Windows Presentation Foundation)
* **Архитектурный паттерн:** MVVM (CommunityToolkit.Mvvm)
* **База данных:** SQLite, Entity Framework Core
* **Инструменты тестирования:** чек-листы, баг-репорты, анализ логов, SQL-проверки данных
