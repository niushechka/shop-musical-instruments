# PianoBar — магазин музыкальных инструментов

Десктопное приложение для покупки и учета музыкальных инструментов на C# / WPF. 

Изначально проект создавался как курсовая работа по ООП, а затем использовался для выполнения практических заданий по дисциплине «Тестирование ПО».

## Основные функции
* Каталог товаров с поиском и фильтрами по категориям и брендам
* Корзина с подсчетом общей стоимости
* Оформление заказа с выбором даты и времени доставки
* Личный кабинет клиента с историей покупок
* Панель администратора для добавления товаров, изменения цен и обработки заказов
